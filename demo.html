💧 LiquidGlass

One component. All props. Pure SVG feDisplacementMap via backdrop-filter: url().

The fix — how backdrop-filter url() works

The SVG filter lives in the document (not inside the element). backdrop-filter: url(#filterId) applies it to everything behind the element — displacing the backdrop, not the element itself. This is the difference between real liquid glass and just blurring.

THE CORRECT PATTERN
/* 1. SVG filter lives in the document, NOT inside the element */
<svg style="position:absolute;width:0;height:0">
  <defs>
    <filter id="lg">
      <feImage href="data:image/png;base64,..." result="tex"/>
      <feDisplacementMap
        in="SourceGraphic"  ← the backdrop content
        in2="tex"
        scale="20"
        xChannelSelector="R"
        yChannelSelector="G"
      />
    </filter>
  </defs>
</svg>

/* 2. Apply via backdrop-filter — this warps the background, not the element */
.glass-surface {
  position: absolute;
  inset: 0;
  /* KEY: backdrop-filter with url() reference */
  backdrop-filter: url(#lg);
  -webkit-backdrop-filter: url(#lg);
  background-color: rgba(255,255,255,0.10); /* tint */
  border: 1px solid rgba(255,255,255,0.20); /* rim */
}
Shape Variants

variant="pill" | "rounded" | "circle" | "squircle" | "sharp"

Tint Prop — tint="rgba(...)"

Change the fill color of the glass surface. The displacement effect is separate from the tint.

Scale Prop — warp intensity

The scale attribute on feDisplacementMap controls how far each pixel is displaced. Live slider below updates it in real time.

scale= 20
Noise Types — noiseType prop

Each generates a different texture. The R channel drives x-displacement, G drives y.

blur + displacement combined

Add a small blur alongside displacement for a frosted-liquid hybrid. Pure displacement (blur=0) gives the sharpest refraction.

Wobble Animation — wobble prop

CSS scale animation creates an organic liquid-blob feel. Works great for circles.

as Prop — render as any element

as="div" | "a" | "span" | "button" — same glass, different semantics.
